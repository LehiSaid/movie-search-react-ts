# 🎬 Movie Search App

A simple movie search application built with **React** and **TypeScript**, consuming data from the **TMDB API**.

This project was created for learning purposes, focusing on API consumption, state management and component-based architecture using React.

---

## 🚀 Features

- Search movies by name
- Fetch real-time data from TMDB API
- Display movie titles dynamically
- Handle loading and empty search states
- Built with modern React (Hooks)

---

## 🛠️ Technologies Used

- React
- TypeScript
- Vite
- Axios
- TMDB API
- HTML5 & CSS3
